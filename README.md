# Twin Lanterns — Spot the Difference

Three hand-drawn-in-code scenes (Harbour Dawn, Garden Lane, Market Dusk). Each pair of pictures hides 7–9 differences: extra clouds, changed colours, missing crates, a cat that was not there before.

How to play:
- Click or tap a difference on either picture to mark it — a ring appears on both.
- Beat the 2:30 clock per scene; a wrong click costs 2 seconds.
- Stuck? The Hint button pulses one hiding difference (3 per scene).
- Toggle the Lens for a magnifier, or play by keyboard: arrow keys move the ring, Enter marks it. Keys: H hint, L lens, M mute.
- Clear all three scenes to win.

Open `game/index.html` in any browser — no build step, no network needed.
